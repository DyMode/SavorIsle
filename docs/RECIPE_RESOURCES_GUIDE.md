# 菜谱资源包与批量管理

管理员从配方页标题栏的资源包图标进入。有有效体验或正式臻享权益即可下载全部分类，两者范围相同。可以单包下载，也可用“下载全部”获取全目录；搜索不会缩小“全部”的范围。下载任务在 NAS 后台运行，切换页面或刷新浏览器后可继续查看进度。展开任务会打开操作窗口；收起保留小入口，关闭窗口隐藏小入口，两种操作都不会停止后台下载。可从资源页的下载任务图标重新打开。菜谱准备完成后，从任务面板进入核对，再确认加入配方库；厨房资料下载完成即可使用。

已获取相同内容会跳过；家庭修改过的配方和回收站内容会保留。可以安全更新的旧版在核对页提示更新，确认后保留原配方编号。彻底删除的内容可以再次下载。权益到期后，已导入配方仍可使用和导出。

下载时可以切换应用页面，回到资源页查看结果。完成但尚未加入的内容也可从导入历史找回。菜谱获取由 NAS 后台处理，关闭页面不会中断；完成内容可从导入记录找回。NAS 重启会终止尚未完成的任务，可重新获取。基础资料逐包同步，切换应用页面会继续，关闭浏览器可能需要重新发起。部分分类失败时，先核对已下载内容；本批处理完后可重新下载失败包。

基础资料的资料包面板可“下载全部”，已有最新版本会跳过，其余内容逐包同步；失败不阻止其他包，结束后可以重试失败包。

配方页从“列表操作”进入“批量管理”，可逐道勾选、选择已显示内容，或选择全部符合条件的内容。全范围选择会固定当时的清单，之后新增的配方不会被处理。筛选“来自菜谱包”可集中管理导入示例。

普通配方批量“移到回收站”；在回收站可以批量“恢复为草稿”或“彻底删除”。确认页显示数量和部分名称，彻底删除无法恢复。发生修订冲突时保留失败项，用“重新核对失败项”更新选择后再次确认。选择范围30分钟内有效，一次最多5000道。

首批资源：[13个分类、144道图文配方](https://github.com/DyMode/SavorIsle-Packs/tree/main/recipes)。原作链接、作者、完整步骤数量及来源说明见公开内容清单。

厨房资料与菜谱共用的索引可在“我的 → 资料与工具 → 补给站”管理。

补给站可选择“自动选择”、GitHub 直连、GH-Proxy、GHFast 或自定义加速。自动模式先使用最近成功的线路；下载尚未完成时，间隔 0.8 秒尝试其他线路，采用最先下载完整并通过校验的结果，取消其他请求。加速仅用于官方 GitHub 资源，自定义资源源地址保持原样。自定义加速地址应是公网 HTTPS 代理前缀，支持在其后拼接完整 GitHub 原始链接。下载线路不会改变资料编号与已有配方引用。

厨房资料的整批下载只读取一次完整索引。菜谱包经 SHA-256 校验后缓存在 NAS 中，重复准备相同内容可复用缓存；缓存上限约 256 MiB，空间不足时优先清理较早使用的包。资源版本更新、缓存损坏或缺失时重新下载。选择线路后点“保存来源”，下一次下载生效。

导入核对中“进入编辑”用于整理候选内容。“保存并返回核对”保留修改，“放弃本次修改”恢复编辑前的候选；两者均不提前入库。跳过某道配方使用独立的“跳过这道”。确认入库后，配方才进入家庭配方库；入库前自行修改的资源配方也会受到更新保护。

确认入库后本次导入结束：勾选内容入库，未勾选内容跳过。编辑中的候选必须先保存或放弃修改，才能确认入库。进入编辑但没有改动的资源配方仍可接收后续更新。

菜谱包按“一次下载、一批核对、一次入库”处理。当前批次尚未核对时，再选相同菜谱包会回到核对；选其他包或“下载全部”会提示先完成或放弃当前批次。服务端同样拒绝创建第二批待核对菜谱。全部失败显示未完成并可重试；部分成功须先处理已准备的菜谱，之后再下载失败包。返回资源任务会恢复之前的任务窗口。移除关联待核对内容的任务前会确认，并清理候选与关联草稿；已入库配方保留。核对完成后任务记录自动结束，导入记录仍保留供查看。
