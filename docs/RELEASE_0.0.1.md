# 味屿 0.0.1

把喜欢的味道，留在家里。

味屿是一款部署在家庭 NAS 上的配方与下厨管理应用。手机浏览器即可记录配方、换算材料、安排制作，与家人一起决定吃什么。

## 首次发布

- 家庭配方：材料分组、图文步骤、份量换算、收藏与个人草稿。
- 下厨安排：待做清单、制作计划、备料采购、步骤跟做与计时。
- 家人选菜：菜单、点菜册与菜单码；支持图片多选、连续加载、份量备注和拖动排序，岛主统一配置对外分享地址。
- 厨房资料：食材、品牌、产品、厨具和资料包，支持同步、启停与删除。
- 菜谱资源：分类图文配方、后台下载任务、统一核对与批量管理；支持自动下载加速与已校验资源缓存。
- 配方整理：JSON/ZIP 导入、屿灵与外部助手 SKILL/MCP 接入，确认入库由用户完成。
- 账号与数据：家庭成员、外观偏好、备份恢复与在线臻享状态。基础功能与臻享范围见[协议说明](LEGAL.md)。

## 飞牛安装与数据管理

- 安装前阅读并同意用户协议与隐私说明；应用内可随时查看。
- 卸载默认保留家庭数据；选择删除全部数据时同步清理升级备份和日志，失败明确提示。
- 升级前备份家庭数据，保留最近三份完整备份；失败中止并尝试恢复此前运行的服务。
- 服务停止不依赖有效的端口配置，强制停止后等待进程退出。

## 安装

要求 fnOS 1.2.0701 或更新版本，在应用中心手动上传对应架构的 FPK。默认服务端口为 `18780`，安装时可修改。

| NAS 架构 | 安装包 |
| --- | --- |
| x86-64 | `savorisle-0.0.1-native-x86.fpk` |
| ARM64 | `savorisle-0.0.1-native-arm.fpk` |

ARM64 包通过交叉构建、程序架构及安装包结构校验，尚未在 ARM fnOS 实机上验证安装。

发布附件包含 `SHA256SUMS.txt` 和外部助手工具包 `savorisle-tools-0.0.1.zip`。
