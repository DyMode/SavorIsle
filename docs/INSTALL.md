# 安装味屿

## 飞牛 fnOS

根据 NAS 的处理器架构选择对应的安装包，系统要求见安装包说明。

1. 在应用中心选择手动安装，上传与 NAS 处理器架构匹配的 FPK 安装包。
2. 安装时可设置服务端口，默认端口为 `18780`。首次从飞牛桌面打开味屿，以 NAS 管理员身份创建家庭管理员。
3. 安装完成后，从飞牛桌面打开「味屿」。
4. 手机浏览器访问 `http://NAS地址:服务端口/app/savorisle/`，使用味屿账号登录。

卸载时选择保留数据，重新安装即可恢复原有家庭数据和账号。端口留空会沿用之前的设置，打开味屿后使用原有账号。

飞牛桌面入口支持 NAS 身份登录与味屿成员关联；家庭管理员可以管理成员和账号权限。

## 账号与家庭

首次从飞牛桌面创建家庭管理员时，会同时绑定当前 NAS 管理员身份；之后飞牛登录和用户名密码登录进入同一个账号。在「我的 → 家庭成员」添加成员；个人收藏、草稿和外观偏好分别记录在成员账号下，家庭配方供家人查看。

## 数据与备份

应用数据保存在飞牛应用目录的 `var/data` 中。管理员进入「我的 → 数据管理 → 系统备份」创建与下载备份，也可以设置自动备份。

恢复备份前按页面提示核对备份内容，恢复完成后重新登录。运行日志位于应用 `var` 目录。

## 访问地址

| 入口 | 地址 |
| --- | --- |
| 飞牛桌面 | 味屿应用图标 |
| 手机或电脑浏览器 | `http://NAS地址:18780/app/savorisle/` |

安装包内包含服务程序、前端页面和应用图标。构建方式见 [构建说明](BUILD.md)。

状态诊断日志位于 `/var/apps/savorisle/var/status.log`。仅记录检查失败、启动/停止与恢复状态，不记录密码、令牌或请求内容。单个日志上限约 2 MB，保留两份旧日志 `status.log.1` 和 `status.log.2`，总量约 6 MB；运行日志仍为 `app.log`。反馈异常时，请提供通知时间及对应日志片段。

岛主在「我的 → 分享设置」填写完整的对外访问地址（例如 `https://你的域名/app/savorisle`）。菜单、点菜册的对外链接和菜单二维码统一使用此地址；内部预览仍使用当前访问入口。未配置时不能创建、重发或复制分享入口。清空配置不会撤销已经发出的链接，可在对应分享面板停止已有分享。

运行状态检查使用不依赖数据库的 `/health/live`，同时验证 TCP 和统一网关，短暂失败会复查一次，总检查预算约 2.5 秒。启动仍使用 `/health/ready` 校验数据库与两个入口；数据库等待最多约 2 秒。状态诊断日志中的 `check=live/ready` 区分这两种检查。

### 0.0.1 安装与清理行为

安装前需阅读并同意安装向导中的用户协议与隐私说明。协议也可在应用内查看。

升级前停止服务并备份家庭数据；仅保留最近三份完整升级备份。备份失败会中止升级、清理本次残缺备份，并尝试恢复此前运行的服务。

卸载默认保留家庭数据、端口配置和升级备份。选择删除所有数据时，会同时删除主数据目录、升级备份及应用日志；删除失败会明确报错。此前自行导出到其他位置的备份不受影响。
