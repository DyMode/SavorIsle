# 屿灵使用说明

屿灵将文字、图片和文档整理为配方，支持补充要求并调整结果。使用前需具备屿灵功能，并在「屿灵设置」配置模型服务地址、模型和 API 密钥。

## 整理配方

1. 在新增配方页面粘贴文字或添加附件，点击「交给屿灵」。
2. 整理期间可以切换页面，通过顶部任务入口查看进度；也可点击「先停一下」。
3. 完成后预览结果，多份配方逐份选择「进入编辑」，核对材料、厨具与步骤后发布。

进入编辑的结果保存为个人草稿，可从配方库草稿入口继续。取消剩余结果不会删除已交接的草稿；发布后配方进入家庭配方库。

## 提醒与重试

完成或失败时会显示提醒，点击可查看结果或原因。关闭提醒不会删除结果。整理失败或停止后，原文与附件保留，可以修改后重新提交；取消未采用的结果会清除对应结果与输入。

## 模型服务

设置页显示每条服务今日已用、剩余次数和重置时刻。次数按家庭在该服务上提交的任务统计，以 UTC 日重置；失败和停止的任务计入次数，连接测试不计入。模型调用费用由所用服务商收取。

## 匹配营养

在食材或食品的营养编辑页使用「匹配营养」，可根据名称、产品信息或粘贴的包装营养表生成建议。核对基准用量、单位和来源后采用建议，保存资料后生效；未知项目留空。匹配与配方整理共用所选模型服务的每日额度。
